<=>PROJECT DESCRIPTION<=>:

        This is a User Management Dashboard built using React.js. The application provides a user-friendly interface to manage users by allowing the following functionalities:
    A.Viewing Users: Displays a list of users upon loading the website.
    B.Adding Users: Users can be added by triggering a pop-up form where their details such as first name, last name, email, and department can be entered.
    C.Editing Users: Each user has an associated "Edit" button that triggers a pop-up form, enabling the modification of their details.
    D.Deleting Users: A delete button allows users to be removed from the list.
        The project leverages the reactjs-popup library for creating dynamic pop-up forms, enhancing the user experience by allowing them to add, edit,
          and delete user details without navigating away from the main page.

<=>Features<=>:

1.User List: Displays a list of users.
2.Add User: Triggers a pop-up where you can add user details.
3.Edit User: Allows you to edit user details through a pop-up.
4.Delete User: Deletes a user from the list.

<=>Technologies Used<=>:

1.React.js
2.Reactjs-popup library
3.Javascript
